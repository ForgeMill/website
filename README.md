# Forge Website

This directory contains the official marketing website for Forge.

## Overview

- **Brand**: The visual identity is defined by the `Forge.png` guide, featuring a dark, industrial aesthetic.
- **Framework**: This is a static site built with pure, dependency-free HTML, CSS, and JavaScript.
- **Content**: The site includes a hero section, a list of product features, and a responsive navigation menu.

## Local Development

To view the website, simply open `index.html` in any modern web browser. There is no build step required.

```sh
# On Windows
start website/index.html
```

## Deployment

This is a static site that can be deployed to any static hosting provider, such as GitHub Pages, Vercel, or Netlify.

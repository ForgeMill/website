# ForgeMill Website v1.0

Official production-quality website for ForgeMill, featuring a premium dark industrial aesthetic inspired by a blacksmith forge.

## Features
- **Cinematic Visuals**: Custom-engineered SVG logo with animated hammer strikes, orange sparks, and molten glow.
- **Dynamic Background**: High-performance `<canvas>` particle system for floating embers and smoke.
- **Scroll Orchestration**: `IntersectionObserver` used for lighting up the Engineering Pipeline and Roadmap stages.
- **Premium Interactivity**: Glassmorphism waitlist form, button ripple effects, and steel-to-glow hover transitions.
- **Zero Dependencies**: Built entirely with Vanilla HTML5, CSS3, and JavaScript.
- **Performance Optimized**: Semantic HTML, CSS hardware acceleration, and minimal JS payload.

## Technology Stack
- HTML5
- CSS3 (Custom Variables, Flexbox/Grid, Keyframe Animations)
- Vanilla JavaScript (ES6+)

## Deployment
This site is designed to be hosted directly on **GitHub Pages**.

1. Push this `website/` directory to your repository.
2. Go to Repository Settings > Pages.
3. Select the branch and folder (`/website`) and save.

## local Development
Simply open `index.html` in any modern web browser.
